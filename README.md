# ⚛️ Meus Estudos de React - freeCodeCamp

Repositório criado para centralizar e organizar todos os exercícios, componentes e microprojetos desenvolvidos durante a trilha de React do freeCodeCamp.

O objetivo principal é documentar a minha evolução, manter o perfil organizado e praticar conceitos essenciais da biblioteca.

---

## 📂 Índice de Componentes e Oficinas

Abaixo estão os links diretos para cada etapa concluída. Você pode clicar nos links para navegar direto pelas pastas de código:

### 🗂️ [01 - Navbar Component](./01-navbar-component)
* **Descrição:** Criação de uma barra de navegação responsiva e reutilizável.
* **O que pratiquei:** * Estruturação de componentes funcionais em React.
  * Sintaxe JSX e suas regras.
  * Uso do atributo `className` para estilização com CSS externo.
  * Exportações nomeadas (`Named Exports`) para modularização.

### 🗂️ [02 - Footer Component](./02-footer-component)
* **Descrição:** Construção de um rodapé semântico e estruturado.
* **O que pratiquei:**
  * Uso de tags semânticas do HTML5 (`<footer>`).
  * Organização de layout utilizando listas aninhadas (`<ul>`, `<li>`).
  * Alinhamento e responsividade com CSS Flexbox.
